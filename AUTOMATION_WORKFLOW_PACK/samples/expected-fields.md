# Expected response fields

- Accessibility pre-audit: final URL, summary and eight evidence-backed findings.
- Security baseline: final URL, summary and nine passive response findings.
- Product snapshot: title, price, currency, availability, canonical URL, source and fingerprint when exposed publicly.
- Tender/RFP extraction: title, references, deadlines, value, mandatory requirements, submission instructions, scope, evaluation criteria, cautions and completeness.

An empty or caution result is valid when the public source does not expose the required signal. Do not turn missing data into an invented value.
